Simulador de Investimentos em FIIs
Projeto desenvolvido como parte de um desafio da DIO, utilizando o Microsoft Excel para criação de um simulador de investimentos em Fundos de Investimento Imobiliário (FIIs).
A proposta do projeto é permitir a realização de simulações de investimentos de longo prazo, considerando diferentes valores de aporte, períodos de investimento, taxas de rendimento e perfis de investidor.
O objetivo do projeto é desenvolver uma ferramenta em Excel capaz de auxiliar na visualização do potencial crescimento de um investimento ao longo do tempo, permitindo analisar alguns pontos como:
Valor do investimento mensal; Período de investimento; Taxa de rendimento mensal; Patrimônio acumulado; Estimativa de dividendos mensais; Projeções de longo prazo; Perfil de investidor.
O projeto foi desenvolvido com foco educacional e de simulação, não constituindo recomendação de investimento.
A funcionalidade do simulador é permitir inserir informações relacionadas ao perfil do investidor (salário mensal, percentual sugerido para investimento, investimento mensal, período de investimento em anos, taxa de rendimento mensal
e perfil de investidor) e realizar projeções a partir desses dados informados.
A partir dessas informações, a planilha realiza os cálculos necessários para apresentar diferentes cenários de acumulação de patrimônio.
O simulador apresenta projeções para diferentes períodos (por anos) e para cada período, são calculados valores relacionados ao patrimônio acumulado e aos dividendos mensais estimados.
Essa estrutura permite visualizar como o período de investimento e os aportes recorrentes podem influenciar os resultados da simulação.
O projeto também apresenta uma sugestão de distribuição percentual entre diferentes categorias de Fundos Imobiliários (papel, tijolo, híbridos, FOF's, desenvolvimento e hotelaria), de acordo com o perfil selecionado
A planilha possui uma Tabela de Apoio responsável por armazenar os percentuais utilizados na distribuição de acordo com os perfis (conservador, moderado e agressivo)
O projeto foi desenvolvido utilizando recursos do Excel, incluindo: fórmulas financeiras, fórmulas de busca, cálculos matemáticos, referências entre células, tabelas de apoio, formatação de células, organização de dados, etc...
Entre os recursos utilizados na construção do simulador estão fórmulas como: FV; PROCV; Operações matemáticas e financeiras.
Também foram utilizados nomes definidos para facilitar a organização e a leitura das fórmulas, como: aporte, patrimônio, qtd_anos, taxa_mensal
O resultado desse projeto é uma ferramenta educacional de simulação que permite visualizar diferentes cenários de investimento de forma organizada e automatizada.
A partir dos dados inseridos pelo usuário, a planilha apresenta projeções de patrimônio e dividendos para diferentes períodos, além da distribuição dos investimentos de acordo com o perfil selecionado.
O desenvolvimento deste projeto proporcionou a aplicação prática de conhecimentos relacionados a: organização e estruturação de dados no Excel, utilização de fórmulas financeiras; criação de simulações, projeções de longo prazo,
utilização de tabelas auxiliares, fórmulas de busca, automatização de cálculos, estruturação de uma ferramenta interativa, apresentação de informações financeiras de forma organizada.
Além do conhecimento técnico, o projeto contribuiu para o desenvolvimento do raciocínio lógico aplicado à construção de soluções utilizando o Excel.
Este projeto possui finalidade educacional e foi desenvolvido como parte de uma atividade da DIO.
